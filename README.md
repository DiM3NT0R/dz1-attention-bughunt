# ДЗ 1. Внимание и поиск ошибок

- [dz1-attention.ipynb](dz1-attention.ipynb) содержит реализацию четырёх функций и вывод 17 открытых проверок.
- [dz1-bughunt.ipynb](dz1-bughunt.ipynb) содержит исправления для варианта 42, таблицу ошибок и обучение символьной модели.
- [REPORT.md](REPORT.md) содержит разбор ошибок, результаты обучения, график и пример генерации.

## Запуск в Google Colab

1. Скачайте оба файла `.ipynb` и откройте их по очереди через меню **Файл → Загрузить блокнот** в [Google Colab](https://colab.research.google.com/).
2. В каждом ноутбуке выберите **Среда выполнения → Сменить среду выполнения → T4 GPU**. Если в списке доступна версия среды **2026.07**, её можно выбрать для запуска с Python 3.12.13 и предустановленным PyTorch 2.11.0. [Версии среды Colab](https://research.google.com/colaboratory/runtime-version-faq.html)
3. Выберите **Среда выполнения → Выполнить все**. В обоих ноутбуках ожидается строка `пройдено 17 из 17`. Проверки используют CPU. Ячейка обучения во втором ноутбуке автоматически выбирает CUDA и выводит имя видеокарты и версию CUDA.
4. Во втором ноутбуке после обучения откройте панель **Файлы** слева и скачайте `loss.png` и `generation.txt`. Те же результаты видны в выводе ячеек.

Данные создаются в самом ноутбуке. Файлы корпуса, Google Drive и ключи доступа для вычислений не нужны.

## Локальный запуск

Сохранённый прогон на CPU выполнен в Windows с Python 3.12.10, PyTorch 2.15.0+cpu, Matplotlib 3.10.9 и четырьмя потоками PyTorch. Выполните команды из корня репозитория.

```sh
python -m venv .venv
```

Команда активации для PowerShell — `.venv\Scripts\Activate.ps1`, для Linux и macOS — `source .venv/bin/activate`.

```sh
python -m pip install torch==2.15.0 --index-url https://download.pytorch.org/whl/cpu
python -m pip install matplotlib==3.10.9 jupyterlab
python -m jupyterlab
```

В JupyterLab откройте оба ноутбука и выполните **Run → Run All Cells** в каждом. `loss.png` и `generation.txt` появятся рядом с ноутбуком.

## Параметры эксперимента

| Параметр | Значение |
|---|---|
| Seed варианта | 42 |
| Seed обучения и seed генерации | 0 и 0 |
| Корпус | «алгоритм внимания смотрит на все позиции сразу. » × 200 |
| Корпус и словарь | 9 600 символов, 19 уникальных |
| Модель | 400 640 параметров, контекст 64, ширина 128, 4 головы, 2 блока, FFN 512, dropout 0,1 |
| Обучение | AdamW, learning rate 0,0003, 600 шагов, батч 32 |
| Генерация | Начальный символ «а», 200 новых символов, temperature 0,8, top-k 10 |

Перед обучением и генерацией seed устанавливается заново. Ячейка обучения включает детерминированные алгоритмы PyTorch. Численные значения и сгенерированный текст могут отличаться между CPU и CUDA или между версиями PyTorch. [Воспроизводимость в PyTorch](https://docs.pytorch.org/docs/2.15/notes/randomness.html)
